      # Life Tracker

A personal productivity and life tracking application designed to help track daily activities, tasks, focused work, and personal reflections in one place.

## ✨ Features

### 📊 Activity Tracker
- Track recurring activities such as DSA, Python, SQL, Exercise, College, and Projects.
- Four-state daily tracking:
  - Not Recorded
  - Partial
  - Completed
  - Incomplete
- Activity start and end dates.
- Completion and streak analytics.

### 📌 Task Manager
- Create, edit, delete, and complete tasks.
- Priorities: Low, Medium, High.
- Task statuses:
  - To Do
  - In Progress
  - Completed
  - Blocked
- List and Kanban views.
- Due dates, tags, reminders, and recurrence support.

### 🎯 Focus
- Pomodoro timer.
- Focus, short-break, and long-break modes.
- Track completed focus sessions.
- Associate focus sessions with activities or tasks.

### 🎵 Ambient Sounds
- Mix multiple ambient sounds.
- Individual and master volume controls.
- Presets for different focus environments.

### 📝 Diary
- Write an optional diary entry for each day.
- Browse previous and upcoming dates.
- View daily activities, tasks, focus sessions, and diary entries together.

### 📈 Analytics
- Activity completion trends.
- Streaks and consistency.
- Task statistics.
- Focus-time analytics.
- Diary statistics.
- Calendar-based progress view.
- Monthly review.

## 🛠️ Tech Stack

### Backend
